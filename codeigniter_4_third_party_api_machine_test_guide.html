1. Machine-test scenario

Assume the interviewer gives you this API:

GET https://restcountries.com/v3.1/name/{country}

Requirement:

  • Create a CodeIgniter 4 page.
  • Enter a country name.
  • Use jQuery AJAX to send the request to CodeIgniter.
  • CodeIgniter calls the third-party API.
  • Decode the JSON response.
  • Return a clean JSON response to the browser.
  • Display country information.
Browser ↓ AJAX CodeIgniter Controller ↓ Validate request ↓ Third-party API ↓ JSON response ↓ Process response ↓ Return JSON ↓ Browser displays result

2. Workflow to memorize

  1. Read the API documentation.
  2. Test the API in Postman.
  3. Identify HTTP method: GET, POST, PUT, PATCH or DELETE.
  4. Identify URL and path parameters.
  5. Identify query parameters.
  6. Identify authentication: Bearer token, API key, Basic Auth, OAuth, etc.
  7. Identify required headers.
  8. Identify request body and JSON structure.
  9. Create the CodeIgniter HTTP client.
  10. Send the request.
  11. Check HTTP status.
  12. Decode JSON.
  13. Handle API errors.
  14. Process or save the response.
  15. Return JSON to the frontend.
  16. Test through AJAX/browser.

4. Environment and tokens

Never hard-code real API tokens in PHP source code. Do not commit them to GitHub. Put secrets in .env or another secure secret store.

Example .env:

CI_ENVIRONMENT = development

THIRD_PARTY_API_URL = https://example.com/api
THIRD_PARTY_API_TOKEN = your_real_token_here
THIRD_PARTY_API_KEY = your_real_api_key_here

Read them in CodeIgniter with:

$token = env('THIRD_PARTY_API_TOKEN');
$apiKey = env('THIRD_PARTY_API_KEY');
The token shown above is a placeholder only. In a real machine test, replace it with the credential supplied by the interviewer.

6. Controller

Create:

app/Controllers/CountryController.php

Complete controller:

<?php

namespace App\Controllers;

class CountryController extends BaseController
{
    public function index()
    {
        return view('country/index');
    }

    public function search()
    {
        $country = trim($this->request->getPost('country'));

        // 1. Validate input
        if ($country === '') {
            return $this->response
                ->setStatusCode(422)
                ->setJSON([
                    'status'  => false,
                    'message' => 'Country name is required.'
                ]);
        }

        try {

            // 2. Create HTTP client
            $client = \Config\Services::curlrequest([
                'timeout' => 10,
            ]);

            // 3. Call third-party API
            $url = 'https://restcountries.com/v3.1/name/'
                 . urlencode($country);

            $response = $client->get($url);

            // 4. Check HTTP status
            if ($response->getStatusCode() !== 200) {
                return $this->response
                    ->setStatusCode(400)
                    ->setJSON([
                        'status'  => false,
                        'message' => 'Third-party API returned an error.'
                    ]);
            }

            // 5. Decode JSON
            $data = json_decode(
                $response->getBody(),
                true
            );

            // 6. Check response data
            if (empty($data)) {
                return $this->response
                    ->setStatusCode(404)
                    ->setJSON([
                        'status'  => false,
                        'message' => 'Country not found.'
                    ]);
            }

            // 7. Extract only required fields
            $countryData = $data[0];

            $result = [
                'name' => $countryData['name']['common'] ?? null,
                'official_name' => $countryData['name']['official'] ?? null,
                'capital' => $countryData['capital'][0] ?? null,
                'region' => $countryData['region'] ?? null,
                'population' => $countryData['population'] ?? 0,
                'currency' => array_key_first(
                    $countryData['currencies'] ?? []
                ),
            ];

            // 8. Return JSON to browser
            return $this->response->setJSON([
                'status' => true,
                'data'   => $result
            ]);

        } catch (\Exception $e) {

            // 9. Handle connection/API errors
            return $this->response
                ->setStatusCode(500)
                ->setJSON([
                    'status'  => false,
                    'message' => 'Unable to connect to third-party API.'
                ]);
        }
    }
}

$('#countryForm').submit(function(e) {

                    <p>

                    </p>

                    <p>
                        <strong>Population:</strong>
                        ${data.population ?? '-'}
                    </p>

                    <p>
                        <strong>Currency:</strong>
                        ${data.currency ?? '-'}
                    </p>
                `);

            } else {

                $('#result').html(
                    `<p class="error">${response.message}</p>`
                );
            }
        },

            if (xhr.responseJSON) {
                message = xhr.responseJSON.message;

            $('#result').html(
                `<p class="error">${message}</p>`
            );
        }

    });

});

</script>

8. GET API requests

Simple GET

$client = \Config\Services::curlrequest();

$response = $client->get(
    'https://example.com/api/users'
);

$data = json_decode(
    $response->getBody(),
    true
);

GET with query parameters

$response = $client->get(
    'https://example.com/api/users',
    [
        'query' => [
            'country' => 'India',
            'status'  => 'active',
        ]
    ]
);

$response = $client->post(

            'Content-Type' => 'application/json',
        ],

        'json' => [

        ]
    ]
);

$data = json_decode(
    $response->getBody(),
    true
);

10. Bearer-token authentication

This is one of the most important patterns to remember for interviews.

Example API documentation:

Authorization: Bearer YOUR_TOKEN

Put the real token in .env:

THIRD_PARTY_API_TOKEN = your_real_token_here

Then:

$token = env('THIRD_PARTY_API_TOKEN');

$response = $client->get(
    'https://example.com/api/users',
    [
        'headers' => [
            'Authorization' => 'Bearer ' . $token,
            'Accept'        => 'application/json',
        ]
    ]
);

POST + Bearer token

$token = env('THIRD_PARTY_API_TOKEN');

$response = $client->post(
    'https://example.com/api/customer',
    [
        'headers' => [
            'Authorization' => 'Bearer ' . $token,
            'Accept'        => 'application/json',
            'Content-Type'  => 'application/json',
        ],

        'json' => [
            'name'  => 'John',
            'email' => 'john@example.com',
        ]
    ]
);

$result = json_decode(
    $response->getBody(),
    true
);

11. API-key authentication

Some APIs use an API key instead of a Bearer token.

API key in header

$apiKey = env('THIRD_PARTY_API_KEY');

$response = $client->get(
    'https://example.com/api/users',
    [
        'headers' => [
            'X-API-KEY' => $apiKey,
            'Accept'    => 'application/json',
        ]
    ]
);

API key as query parameter

$response = $client->get(
    'https://example.com/api/users',
    [
        'query' => [
            'api_key' => env('THIRD_PARTY_API_KEY')
        ]
    ]
);
Do not assume the authentication format. Read the API documentation and reproduce its required header/body/query format exactly.

12. HTTP status codes and error handling

StatusMeaningTypical action
200OKProcess response
201CreatedProcess created resource
400Bad RequestCheck request data
401UnauthorizedCheck token/API credentials
403ForbiddenCheck permissions
404Not FoundCheck URL/resource
422Validation ErrorFix submitted data
429Too Many RequestsRespect rate limits
500Server ErrorThird-party server problem
503Service UnavailableRetry later if appropriate

Basic status check

$statusCode = $response->getStatusCode();

if ($statusCode >= 200 && $statusCode < 300) {

    $data = json_decode(
        $response->getBody(),
        true
    );

} else {

    // API failed
}

Exception handling

try {

    $response = $client->get($url);

    // Process response

} catch (\Exception $e) {

    return $this->response
        ->setStatusCode(500)
        ->setJSON([
            'status'  => false,
            'message' => 'Third-party API unavailable.'
        ]);
}

13. Saving API data to MySQL

If the API returns:

{
    "id": 101,
    "name": "John",
    "email": "john@example.com"
}

Using a Model

$model = new CustomerModel();

$model->insert([
    'external_id' => $data['id'],
    'name'        => $data['name'],
    'email'       => $data['email'],
]);

Using Query Builder

$db = \Config\Database::connect();

$db->table('customers')->insert([
    'external_id' => $data['id'],
    'name'        => $data['name'],
    'email'       => $data['email'],
]);

Typical architecture

Browser ↓ AJAX ↓ Controller ↓ Validate input ↓ Third-party API ↓ Validate API response ↓ Model / Query Builder ↓ MySQL ↓ JSON response ↓ Browser

14. Professional Service-class approach

For a small machine test, an API call inside the controller may be acceptable. For cleaner code, separate third-party API logic into a Service.

app/
├── Controllers/
│   └── CustomerController.php
│
├── Models/
│   └── CustomerModel.php
│
├── Services/
│   └── ThirdPartyApiService.php
│
└── Views/
    └── customers/

Example service:

<?php

namespace App\Services;

class ThirdPartyApiService
{
    protected $client;

    public function __construct()
    {
        $this->client = \Config\Services::curlrequest([
            'timeout' => 10,
        ]);
    }

    public function createCustomer(array $data)
    {
        $token = env('THIRD_PARTY_API_TOKEN');

        $response = $this->client->post(
            env('THIRD_PARTY_API_URL') . '/customers',
            [
                'headers' => [
                    'Authorization' => 'Bearer ' . $token,
                    'Accept' => 'application/json',
                    'Content-Type' => 'application/json',
                ],

                'json' => $data
            ]
        );

        return [
            'statusCode' => $response->getStatusCode(),
            'data' => json_decode(
                $response->getBody(),
                true
            )
        ];
    }
}

Controller:

use App\Services\ThirdPartyApiService;

public function store()
{
    $data = [
        'name'  => $this->request->getPost('name'),
        'email' => $this->request->getPost('email'),
    ];

    $apiService = new ThirdPartyApiService();

    $result = $apiService->createCustomer($data);

    if ($result['statusCode'] >= 200
        && $result['statusCode'] < 300) {

        return $this->response->setJSON([
            'status' => true,
            'data'   => $result['data']
        ]);
    }

    return $this->response
        ->setStatusCode($result['statusCode'])
        ->setJSON([
            'status'  => false,
            'message' => 'Third-party API request failed.'
        ]);
}

15. Interview-day checklist

Before coding

  • Read the API documentation completely.
  • Test the endpoint in Postman.
  • Confirm method.
  • Confirm URL.
  • Confirm authentication.
  • Confirm headers.
  • Confirm request body/parameters.
  • Inspect a successful response.
  • Inspect an error response.

While coding

  • Keep credentials in .env.
  • Validate user input.
  • Use CodeIgniter's HTTP client.
  • Set a reasonable timeout.
  • Check the HTTP status code.
  • Decode JSON safely.
  • Handle API/network exceptions.
  • Return consistent JSON.
  • Use AJAX if requested.
  • Use Model/Query Builder for database operations.

Before submitting

  • Test success case.
  • Test empty input.
  • Test invalid input.
  • Test invalid token.
  • Test API 404.
  • Test API/network failure if possible.
  • Check browser console.
  • Check CodeIgniter logs.
  • Remove real credentials from source code.
  • Make sure .env is not committed to Git.
Core pattern to memorize:

Read API docs → Test in Postman → Configure token → Create HTTP client → send request → check status → decode JSON → handle errors → process/save data → return JSON → test AJAX/browser.

16. Quick reference — authentication

Authentication Typical CodeIgniter pattern
Bearer Token Authorization: Bearer TOKEN
API Key Header X-API-KEY: KEY
API Key Query ?api_key=KEY
Basic Auth Use the HTTP client's authentication option according to the API documentation.
OAuth 2 Obtain an access token according to the provider's OAuth flow, then send the token as required.
